# Ledger — cycle #8: the Playbook's name falsified; renamed grounded-aligned-progress (GAP)

## Date
2026-06-03

## The claim under test
Is `dag-planning` a sound name for the b3 Playbook?

## Falsification — the name dies, twice
- **"dag-planning" dies — names the mechanic, not the move.** "DAG" is the carrier (a data
  structure); "planning" is the domain. Neither names the +1. Same trap that killed `gate`
  and `anchor` (name the move/result, not the surround). `summit-planning`/`pitch-planning`
  were better register, same category error — and worse, *our private metaphor* for a
  Commons-bound artifact. Rejected.
- **"grounded-progress" dies — lopsided.** It names only the **substrate** grounding
  (*is it actually done?*) and drops the **summit** grounding (*is it the right thing?*),
  reading as summit-independent when the DAG is `root: summit`. The discipline's +1 is the
  **bind** of two groundings; a name carrying one half under-names the bind.
- **Survivor: `grounded-aligned-progress` (alias `GAP`).** Carries both halves explicitly —
  **grounded** in the substrate (V) **and aligned** to the summit (G). The end-goal of the
  bind, not the mechanic.

## Candidates rubbed and dropped
`from-base` (names the origin/method, prepositional fragment, private metaphor) ·
`aligned-progress` (mirror-lopsided — summit half, drops substrate) · `leaned-progress`
(imports an interface marker; names neither grounding) · `wu-wei-progress` (names the
selection style, over-claims a general G0 value) · `true-progress` (clean but heard as
"real" only, loses aligned) · `grounded-n-aligned` (right instinct, informal `-n-`, no
practice-noun).

## The leave was queried (rename guarded itself)
The rename touched three homes — the directory, the Index/title, and `dag.yaml`'s `done_when`
path. Re-running the Touchstone confirmed `b3 = done` only because dir and predicate moved
**in lockstep**; a half-done rename would have flipped `b3` back to `READY`. The discipline
caught its own rename — substrate, not narration.

## State
`library/grounded-aligned-progress/PLAYBOOK.md` (alias GAP). Frontier still empty — all
terminals done. Heals cycle-07's now-stale `dag-planning` path forward (history re-derived,
not rewritten). Remaining leave unchanged: **`write → share`** (Founding gate), deferred.

## Lesson codified
**Name the end-goal / the bind, never the mechanic or the carrier.** And when a discipline
binds two things, a name that carries only one half under-names the +1.
