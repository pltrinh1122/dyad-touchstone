## The distinction it locks (the conflation it fixes)
Stand Down's **Reflect emits TWO orthogonal outputs** — conflated until now (I'd called harvest "the
Reflect phase"):
- **harvest** — survived *proofs* → Ledger. Object: the **work** (ascent plane).
- **`retro:`** — a CSS pass over the *craft*. Object: **how the dyad climbed** (interface plane);
  START/STOP harvested from `fb:`, CONTINUE = the Operator's POV (then rubbed against evidence).
- **Tell:** CSS verbs (keep/start/stop) fit only *behaviors* — you *bank* a proof, you don't "stop" it.

## Why `retro`, not `reflect` (a name refuted by lived use)
`reflect` collided with the SPAOR **Reflect phase** (which *contains* harvest) → the dyad's own agent
conflated it this session. It also **privatized a Commons-shared practice** (the cycle-08 `dag-planning`
trap). Candidates rubbed and dropped:
- `sync` — wrong object (state, not craft); catastrophic git-`sync` collision; re-conflates durability.
- `align` — collides with the existing **[ALIGN]** ritual; names summit-reconcile, not craft.
- `css` — the *right format name* (Commons-shared) but a **noun-acronym, not a verb**; stylesheet
  collision; high-load. Revealed the verb/noun split.
- `tune` — clean verb, but privatizes the shared form + connotes continuous-not-discrete + ambiguous
  object (tune the work? the dyad?).
**Survivor: `retro:`** — the verb-form of the Commons-shared *Retrospective*; no phase/tool collision;
*references* the shared practice (retro = ritual, CSS = its format), never privatizes it.

## Lesson codified
Name the trigger with the Commons-shared verb (`retro:`); keep the shared format name (**CSS**).
**Reflect ≠ one thing: *harvest* the work, *`retro:`* the craft.** A name that collides with the
container it sits in is built to conflate — lived use refuted `reflect` before any argument did.
