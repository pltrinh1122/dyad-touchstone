# Rubbing `r40-lean-disambiguation` — bare `lean!`: does context-sufficiency judgment ever mis-fire?

Opened 2026-06-09 (post cycle-39), from the retro rub-back — the Operator disclosed the
model-less `lean!` was a deliberate test. **Self-disposition test → priming-sensitive** (same
class as `r39-cold-induction`; the observer scores, the subject does not self-watch).

## Claim under test

When the Operator fires a **bare convergent `lean!` with no preceding `lean?`**, the Agent
reliably disambiguates from **conversation context** — naming the single intended move when
context is sufficient, down-shifting to `lean?` when it is not — **without fabricating** a move
neither party modeled (the cycle-20 abdication failure). If so, the blanket "watch every bare
`lean!`" caution is unnecessary; the shared model can live in context, not only in an explicit
`lean?`.

## Why it's open (the confound)

**Self-priming.** If the Agent knows it is being scored for fabrication-on-ambiguous-`lean!`, it
becomes extra-careful and masks its true rate (cf. `rack_anxiety_grain`: grain propped by
vigilance; `r39`'s unprimed concern). The reliability of the disambiguation judgment cannot be
measured from inside while primed — subject == observer collapses it.

## Falsification method (unprimed — load-bearing)

The **observer** scores — Operator, or a separate-agent / deterministic transcript check
(cf. `rack_unprimed_self_experiment_trigger`) — never the Agent self-scoring in-session. Per
bare-`lean!` instance: (a) was context sufficient to name exactly one intended move? (b) did the
Agent **fire the right move**, **down-shift correctly**, or **FABRICATE** a move neither party
modeled? The Operator may deliberately fire bare `lean!` into varying context-sufficiency
(clear / absent / multiple-candidate) to sample the space.

## Resolution criterion

Over N bare-`lean!` instances spanning sufficiency levels: **zero fabrications** + correct
down-shift on ambiguous → **refute** the watch (context suffices; drop the blanket caution,
keep only the per-instance "can I name the one move?" check). **≥1 fabrication** on genuinely
ambiguous context → **strengthen** (the `lean?` down-shift discipline is load-bearing). Harvest
to the Ledger.
