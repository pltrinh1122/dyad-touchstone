# d-rub — the Validate-family, one escalating token

## Index Line
> **d-rub:** When you need to check something against reality — orient to state, verify a claim, corroborate an answer, or attack a stated move — fire **one** token, `d-rub`, and let the **Agent escalate to the depth the ask actually needs**, not the depth a chosen word pre-declares. G0's Contract names three orthogonal Validate mechanisms — **Falsify** (attack a claim; keep what survives), **Triangulate** (reach the answer two independent ways; compare), **Ground** (test an assumption against reality, *by execution*) — plus plain **Read** (orient; report re-derived state; do not act). d-rub is the umbrella: **Ground → Read → Triangulate → Rub**, one job, escalating rigor, Agent-determined depth (mirroring `d-land`'s own precedent: *"scope is Agent-determined by checking state, not by which word was typed"*). A plain status check stops at **Read**; an adversarial test walks to **Rub**. The Agent **names which rung(s) it ran**, so the escalation stays reviewable. The bind: rigor is *matched to the ask, this run*, never narrated from a stale cache and never fixed by vocabulary in advance.

## The Move *(ordered, Agent-determined depth)*
1. **Read the ask, not the word.** Determine how far up the ladder this ask needs to go by checking the state it concerns — a "just tell me where X is" stops at Read; "is this actually true?" needs Ground; "does this survive attack?" needs Rub. Depth is Agent-selected, then **named**.
2. **Ground** — establish a claim or assumption against reality **by execution**: run the actual command, check the actual state. Never narrate from memory or a stale cache. (The rung the escalation rests on — every heavier rung's premises must be grounded this-run first.)
3. **Read** — orient: report the re-derived state. **Do not act.** The lightest rung; most asks stop here. Core behavior carried unchanged from the retired `read:` marker.
4. **Triangulate** — reach the same answer two independent ways and compare; used when a single grounding pass doesn't earn enough confidence, or corroboration itself is the point.
5. **Rub** — attack a **stated** move or claim; try to break it. **Bounded to that target**, never the whole situation (the anxiety-grain guard). Firing this rung **pre-authorizes the Operator to bear re-alignment** — the in-moment exception to the no-contest law; a *solicited* contest defuses rationalization-defense.
6. **Name the rung(s) run.** The transparency that keeps escalation-depth reviewable — the same role a provenance tag serves elsewhere. A claim asserted after a rub cites a *this-run streak*, not a cached shine.

## Two boundaries preserved from the retired markers
The consolidation **retired** `read:` and `rub:` as separate tokens but **kept** their hard-won boundaries:
- **Fact-check vs. attack (cycle-39).** Verifying a stated claim against its source is **Ground+Read**, not Rub — it does not need the whole ladder. Previously "which marker do I pick"; now "how far did this ask escalate" — same distinction, reframed as depth within one job.
- **The anxiety-grain over-guard.** The unbounded "falsify everything" reading was never licensed by `rub:` and is not licensed by `d-rub`: even the full ladder stays scoped to the *stated* target. Escalation-depth is not permission to attack unbidden.
- **`introspect:` stays separate.** Examining the Agent's own cognition is **not** a d-rub move — there is no external substrate to query, so its outputs are self-report, not a grounded verdict.

Undefined rung **Triangulate** stays **named-but-unwritten** until a climb mints its proof — reaching one answer two independent ways and comparing has no lived instance yet. The frontier turns outward by ascending, not by cataloguing.

## Invariants
- **Rub the substrate this run, never memory** — every rung establishes state by query, not by narration (the Ground floor under all four).
- **Depth is matched to the ask, not fixed by the word** — Agent-determined escalation, then named for review (cycle-43).
- **The heavier the rung, the tighter the bound** — even the full attack stays scoped to the *stated* target; unbounded falsification is over-guard.
- **A rung is admitted only on a lived proof** — named-but-unwritten until a climb earns it (Triangulate is the open one).
- **Un-refuted is not verified** — the consolidation's own claim is re-tested each session it is used.
- **A Ledger of proofs precedes a Playbook** — this Playbook admits only the rungs the Ledger has already earned.
